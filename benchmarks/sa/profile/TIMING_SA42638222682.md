## Finish writing before accepting the run

Collection stopping does not stop the benchmark or force worker termination.
Native client measurement and drain finish first. The existing profiling overlay
allows workers up to 900 seconds and the orchestrator up to 1200 seconds for
graceful shutdown and export. These are shutdown limits, not capture durations.
The prior smoke logged all GPU profiler finalizations before vLLM reported
`all workers exited gracefully` at 04:39:11 UTC.

After native shutdown, validate every kernel CSV's companion JSON, finalization
timestamp, symbol coverage, and device/dispatch counts. Files must remain unchanged
through parsing. This reads one worker JSON at a time. Only then can the profile
validation pass; Actions uploads the raw files and validation report afterward.
Timeout, truncation, mismatched counts, changing files or short/out-of-phase capture
remain failures. Failed-run evidence is uploaded too. Wait for upload completion
before treating the workflow as finished. Detailed analysis remains Phase 4.
